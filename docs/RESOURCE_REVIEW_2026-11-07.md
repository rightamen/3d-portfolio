# 资源分类、后台审核与布局修正 — 2026-11-07

用户反馈上一版资源上传能力没有完整贯通首页和管理员后台，并指出首页标题/分类条以及详情文件清单重叠。本次从干净main / 541dfae接续。

## 分类贯通

- 首页先按模型、图片、视频、音频、素材工程包、文档、其他资源筛选；3D模型单独保留道具/角色/场景等细类。非模型不再被推断到3D“综合”。首页只筛选已加载目录，不额外请求或扩张无限墙节点。
- 用户后台 /account/works 增加资源类型、作品状态筛选和真实服务端分页，列表显示类型标识。切换筛选会关闭旧编辑器，返回结果绑定当前账号和筛选条件；不是只过滤首屏数据。
- 编辑器仅模型显示3D细类，更换为其他类型时清理3D细类，按类型上传预览及原件。非模型已有实际附件后可提交审核，不再硬性要求3D模型或额外封面；空作品仍拒绝。
- 管理员新增“资源审核”入口：类型/状态/标题搜索、分页、专用私有详情、图片/视频/音频预览和附件清单、分类调整、发布/拒绝/下架。原站点作品编辑器继续保留，创作者资源从新入口管理。
- 精选展管理也增加类型筛选和类型标识，入展质量门槛不变。
- 管理员分类变更绑定contentVersion，清除旧版策展结果并更新版本。审核状态操作支持version保护；旧调用省略version仍兼容。出现409时要求刷新，防止审核旧内容。
- 管理员详情采用 /api/admin/works/:id 并通过requireAdmin，不放宽公开草稿访问。原文件继续受权限保护。

## 布局修复

首页标题、一级类型条、模型细类和视图切换分开排布，留出入场动画位移的间距；手机可换行，锚点避开顶部导航。
详情文件清单按容器宽度决定布局：窄侧栏将类型/大小、文件名、操作分行，长文件名完整换行；足够宽的容器才用四列，避免只根据屏幕宽度误判侧栏空间。文件用途按三语显示，规格内容可断行。
深浅主题保持，固定深色无限墙的标题在浅色界面仍使用可读的亮色。新增审核卡仅淡入，避免移动交互控件。

## API变化

- GET /api/account/works：resourceType、status，绑定当前用户，先筛选后分页，private/no-store。
- GET /api/admin/works：resourceType、status、q，先筛选后分页，private/no-store；非法类型/状态400。
- GET /api/admin/works/:id：管理员私有详情。
- PATCH /api/admin/works/:id/classification：resourceType、assetCategory、必填version，未知类型/细类400，旧版409。
- PATCH /api/admin/works/:id/status：可选version，旧版409，不影响旧客户端。
- 不新增数据表、环境变量、依赖或上传格式；不改变既有身份验证和原件下载权限。
