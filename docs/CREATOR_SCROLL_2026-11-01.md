## 行为

- 作品标题/筛选、动态、公告、作者介绍、技能、经历与联系区首次进入视野时，
  以 650ms 的透明度和 8–18px 轻微上移入场；同一 DOM 元素不重复播放。
- 桌面细指针设备的横幅背景随滚动产生最多 24px 的轻视差，文字与头像保持稳定。
  横幅离开可视区或设备为触屏时关闭视差。
- 个人页标签导航吸附在站点导航下方，实时测量顶部导航实际高度；
  细进度线展示本页浏览进度，并在键盘滚动/布局变化时更新。
- 向下滚动一段距离后显示返回顶部按钮；返回后聚焦创作者姓名。
  系统减少动态模式下即时返回，普通模式平滑返回。
- 主题色板继续影响导航、进度线和按钮，深色/浅色主题均可使用。

## 性能与可访问性

src/hooks/useCreatorScrollEffects.js 只在 /u/:handle 准备好后运行。
滚动/缩放/布局事件通过单次 requestAnimationFrame 合并；空闲时不循环渲染，
不触发 React 每帧状态更新，也不请求作品数据。
IntersectionObserver 负责入场，MutationObserver 发现迟到的活动/联系内容，
ResizeObserver 更新布局与头部尺寸；移除节点清理待观察和动画，离页释放全部监听。
隐藏标签页停止帧并取消当前动画。

默认内容始终可见，没有等待 JS 才解除的 opacity:0 样式。动画能力缺失时直接显示。
实时切换 prefers-reduced-motion 会取消已有入场动画与视差，并保持文字可读；
键盘聚焦某个入场区域内的控件时，立即取消该区域动画。
作品墙容器和卡片坐标不加入滚动变换，保留既有鼠标/触屏/键盘交互。
