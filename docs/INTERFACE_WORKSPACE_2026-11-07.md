# 统一界面、创作者工作区与系统设置 — 2026-11-07

## 本批目标与范围

参照用户提供的管理员后台截图，重构私人创作者中心，并将新增页面与后台接入统一动效。
本批修改前端，不改访客/管理员授权，不改服务端接口、数据库 schema 或作者主题存储。
功能和验证先在本地完成，尚未部署本批代码。

## 创作者工作区

- /account 默认进入仪表盘；/account/dashboard 保留，原个人概况在 /account/overview。
- 固定侧栏、分组图标导航、快速筛选与 Enter 跳转、当前页高亮、语言切换、个人资料入口和退出。
- 手机改为抽屉，包含焦点约束、Escape、遮罩关闭、滚动锁和关闭后的焦点恢复。
- 所有原有模块继续保留 URL；资料编辑、主题编辑、交易、发布、通知、收藏与安全功能不变。
- 仪表盘新增创作星图：复用管理员后台的 3D 场景，节点来自当前真实统计，点击进入模块或
  作品表现区。键盘提供等效链接；不支持 WebGL/加载失败时提供可用的平面图。
- 星图只在进入可视范围后载入；屏幕外/后台停止持续渲染。轻柔/静态或系统减少动态时
  使用按需渲染，不自动环绕，交互仍可用。关闭动画时关闭自动阻尼。
- 数值在变化时作有限计数过渡；趋势柱与面板入场不引入空闲 JS 动画循环。

## 系统设置

入口：/settings（公开）、/account/system（工作区），以及管理员“系统”页。
顶部设置入口与头像菜单均可进入。管理员系统诊断与原认证流程保持。

八种选择：原生工作室、午夜青蓝、石墨冷银、森林苔绿、暖夜琥珀、原纸暖白、
瓷白极简和跟随系统。可自定义强调色、舒展/紧凑密度、沉浸/轻柔/静态动画及氛围光效。
即时预览、自动保存、恢复默认。跟随系统会响应操作系统深浅色变化。

设置保存在当前浏览器设备的 mrright-interface-preferences-v1，支持同源标签页同步。
不声称跨设备同步。格式错误/旧值/继承属性会回到受限默认值；浏览器阻止存储时仍即时应用，
并明确提示无法持久保存。不是新账号数据，也不会读取或改变任何登录凭据。

界面配色与作者的 accent/surface/font 公开主页主题数据保持独立。
访客选择界面主题时可改变当前显示，但不会写入作者设置；作者试选预览显式优先，
账号设置中的作品场景预览保持真实草稿配色。原生工作室可恢复原有显示逻辑。

所有色板的正文、次要文字在主要背景/面板/抬升表面均检查最低 4.5 对比度；
自定义强调色自动调整到背景与面板至少 3，并从纯黑/白选择按钮文字以达到 4.5。

## 页面动效覆盖

- 首页、发现、作品详情、社区与讨论、登录/注册、作者主页、个人中心全部模块和系统设置。
- 管理员登录与已登录后台各分区，包括动态 API/lazy 加载的面板与列表。
- 页面入场、面板/卡片淡入、局部鼠标柔光、按钮反馈、图表和统计变化。
- 三档强度：沉浸保留完整效果，轻柔缩短入场并简化氛围/视差，静态取消 CSS/WAAPI 入场，
  关闭自动鼠标跟随和星图环绕。操作系统“减少动态”始终优先。
- 不对整个表单、3D 画布、无限墙或对话框叠加滚动位移；焦点进入会立即清除相应入场效果。
- 设置变化实时传递给个人滚动效果、无限墙、公开空间场景和管理星图；路由退出清理观察器、
  动画与事件。模型文件自身的内容播放仍由查看器的交互控制。
