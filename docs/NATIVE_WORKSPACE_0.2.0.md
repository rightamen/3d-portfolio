# 原生创作者工作台 0.2.0

## 目标与界面

用户反馈桌面端过于简陋且依赖网页。本轮把创作者常用流程移入 C++ 原生窗口：探索 / 创作 / 连接分组侧栏；统计卡片、创作星图、趋势和作品表现；收藏库、会话双栏、动态时间线、好友 / 关注列表和资料编辑。继续使用 Win32 + Direct2D / DirectWrite，不引入 WebView 或 Electron。

石墨青绿、午夜蓝、暖纸白主题与中 / 英 / 日覆盖新模块。侧栏、原生输入框、下拉框和发送按钮跟随 DPI 和语言更新。自绘按钮有悬停反馈，星图动效遵守动效开关；最小化或弹窗时暂停。长列表裁剪在页签以下，命中区域同步裁剪，避免滚动项遮盖 / 点击固定页签。输入居中和子窗口裁剪保持 0.1.2 的修复。

## 数据与权限

- 工作台使用 /api/account/analytics：作品、被收藏、下载、已完成订单；7 / 30 / 90 天趋势和逐作品指标来自真实接口。无记录显示 0，不伪造运营数据。
- 收藏夹可新建、改名、删除；删除弹窗说明仅删除夹；作品可加入 / 移出多个收藏夹。收藏仍遵循服务端资源可见性。
- 好友 / 关注列表、创作者发现、好友申请接受 / 拒绝 / 撤回、解除好友，以及创作者详情的关注 / 消息入口直接原生完成。
- 消息仍由现有服务端强制权限：好友直聊，非好友首条请求，接受后继续。原生发送按钮按 thread 状态启用；服务端拒绝依然生效。clientId 保证相同重试不会重复发送。
- 会话使用多行原生 EDIT，Enter 换行 / Ctrl+Enter 发送。未发送草稿按会话保存在内存，切换会话可恢复；退出账号清空。切换会话后的迟到发送响应不能清掉另一会话的输入。
- 历史按 before 序列分页；轮询合并而非覆盖已加载的旧消息；滚动上限按内容计算。可屏蔽 / 解除屏蔽。时间转换为本机时区；展示对方已读状态。
- 通信摘要每 8 秒轮询。仅在前台、窗口可见启用、会话位于最新位置且消息实际完整显示时提交已读序列。查看旧消息不触发追赶到最新位置。
- 关注动态支持作品 / 公告 / 帖子 / 资源分类，原生打开完整内容或作品详情；“标记本页已读”明确提交当前页项目。
- 原生编辑资料保留原有隐私与个人内容字段；原生编辑作品和提交审核保留服务端校验。登录令牌只存内存，退出 / 账号变化后拒绝迟到的私有事件。
- 购买与销售列表分别读取 orders / sales DTO，金额保留分；本版本仅查询，不发起支付或确认收款。

## 后端迁移边界

公开目录 / 精选资格 / 公开详情继续由 C++20 + PostgreSQL 只读视图提供；新增私人工作台界面直接调用现有 Node API。没有更改生产表、环境文件、权限、上传或审核记录，也没有重新部署网站 / Node / C++ 服务。

支付与收款确认、管理后台、社区编辑、注册找回与完整账号安全操作仍在网站。模型渲染仍是第一阶段静态 GLB / Draco / 基础材质范围；聊天为轮询，无文件或语音消息。原生工作台已经扩展，不代表所有后台服务都完成 C++ 重写。

## 验证

开发构建通过：原有 Windows UI 404 项 / 27 组布局；新增工作台 1,553 项 / 189 组布局，涵盖真实好友 / 请求权限、收藏夹、动态、原生发送、历史分页、草稿和退出隔离。原有 Windows 上传 / Unicode 文件名 / 受保护单次下载 / 取消与截断保持原文件 / 无孤儿附件 / 退出撤销通过。

项目 build / lint、376 单测通过；公共 C++ 目录夹具 76 项通过。夹具使用临时服务器根目录、独立 PostgreSQL、测试账号和独立 uploads，结束仅删除该临时根目录。修正旧 finally 中引用已移除 original 变量的残留清理代码；该错误使旧夹具清理退出失败，没有删除仓库上传文件。已复核修正后的夹具退出状态。

人工界面检查使用 computer-use 技能和隔离测试账号；不操作真实用户登录弹窗，不发送真实用户消息。正式源码固定构建、制品摘要和 GitHub 发布记录见 RELEASE_2026-11-08_NATIVE_0.2.0.md。
