# 无限作品墙氛围特效 — 2026-11-01

用户要求为无限作品墙增加特效。本轮只修改该作品墙与其回归测试。

## 效果

- 鼠标附近出现柔和的银紫色光晕。
- 画作悬停时，表面高光跟随局部坐标，画面轻微产生透视倾斜；边缘与阴影随之加强。
- 星空细点和冷色环境光提供背景层次；星点随指针产生轻微视差。
- 漫游速度带来小幅画面倾斜，最靠近视口中心的作品获得低强度强调。
- 所有装饰层均不拦截指针，继续支持画作链接、拖动、键盘与网格切换。

## 动态与性能边界

装饰由 CSS 和原有按需动画循环驱动，不增加外部资源、目录请求、依赖或持续运行的粒子引擎。离屏/隐藏页面会清除鼠标光照状态。触屏保留静态氛围，关闭鼠标光晕与倾斜。减少动态偏好下移除视差、光晕、透视和表面动态反光；运行中更改该偏好也会暂停跟随，并正确清理监听器。

文件：src/components/InfiniteWorks.jsx、src/studio.css、tests/review/marketplace.spec.js。
