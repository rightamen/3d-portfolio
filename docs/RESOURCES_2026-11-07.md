# 多格式资源发布（2026-11-07）

## 使用入口

创作工作室 → 作品（/account/works）。先选择资源类型，再新建草稿；已有作品也能在编辑器中更改类型。

| 类型 | 展示方式 | 可交付文件示例 |
| --- | --- | --- |
| 3D 模型 | 原有按需打开的交互式 3D 查看器 | GLB、GLTF、FBX、OBJ、Blend、压缩包 |
| 图片与插画 | 图片画廊，上一张/下一张 | JPG、PNG、WebP、GIF、TIFF、SVG、PSD |
| 视频与动画 | 原生视频播放器，封面和公开预告 | MP4、WebM、MOV |
| 音频与音效 | 原生音频播放器，封面和试听 | MP3、WAV、OGG、FLAC |
| 素材与工程包 | 封面和图片预览 | PSD、Blend、ZIP、7Z、RAR |
| 文档与资料 | 封面和图片预览 | PDF、TXT、CSV |
| 其他资源 | 封面和图片预览 | 上述允许格式组合 |

每种类型显示适合的上传入口，可批量选择文件，按顺序上传并显示当前进度。部分失败保留已成功文件，可重试。更换类型不会自动删除已有文件。
探索页通过 resourceType 筛选，写入地址栏并重置分页；作品卡和详情显示类型。全部新增文案含中/英/日，适配系统主题与手机。

## 预览与原文件

- 封面、图片画廊、3D 模型、视频预告和音频试听是明确上传的公开预览；不要把需要保密的原文件放进预览入口。预览链接遵循既有公开预览行为，不以草稿链接保密。
- 原文件通过 source 上传。原始字节保持不变，公开作品接口不返回其地址；原路径只允许作者/管理员，响应 attachment、octet-stream、private/no-store。
- JPG/PNG/WebP 原图另生成有界、重新编码的展示图，原图仍受保护。显式上传封面会替换自动展示图。GIF/TIFF/PSD/工程包等请另传封面。
- 文件列表可“下载此文件”，复用登录、订单/权限、短期票据和下载记录。assetId 绑定在数据库票据中，不能通过兑换时更换查询参数切换资源；旧票据兼容默认文件。
- 图片类 JPG/PNG/WebP/GIF 单文件最多 16 MiB，其他允许文件最多 120 MiB。格式随上传入口显示。服务器校验扩展名与文件头；压缩包仅储存，不解压。
- 视频/音频能否播放还取决于浏览器支持的内部编码；没有服务器转码。本批不扩展社区附件、私聊附件或管理员旧上传器。

## 数据与兼容

server/postgres/resourceSchema.js 做增量、幂等升级：

- works.resource_type：七种类型，旧作品默认 model。
- work_assets.kind：保留已有值，增加 video/audio。
- download_tickets.work_asset_id：可空外键，删除资产时撤销对应票据。
- 资源筛选和文件地址索引。

旧模型预览/错误合同、上传 images/models 目录、审核/高分精选规则、付费权限及双重认证保持兼容。新资源原件位于 uploads/resources，自动展示图位于 uploads/work-previews。孤立文件报告工具已纳入新目录，工具只报告，不删除。
上传访问校验优先匹配资产；自动展示图回退仅匹配 work-previews，避免通过作品封面绕过社区资源审核。

## 验证

真实 PNG、WebM、WAV 文件在 tests/fixtures/resources。DB 检查包含发布器真实上传→访客实际播放→作者浏览器下载并逐字节比较、原件保护、自动/显式封面、分文件票据绑定、付费/跨作者拒绝、范围请求、筛选和旧模型默认值。
浏览器检查含批量上传和部分失败、图集翻页、真实媒体解码、分文件下载、三语手机/浅色主题与筛选分页。
回归时发现文件列表入场位移在 focusin 取消动画时会使 pointerup 离开按钮；将文件列表改为仅淡入，下载测试显式启用普通动效覆盖该问题。
