## 范围与行为

用户当前指向 /u/mrright，要求个人作品墙也采用无限屏并优化个人中心。
本次重构公共创作者主页 /u/:handle；账号管理 /account 与后台认证不变。

- 顶部保留创作者自定义横幅、头像、主题色、公开联系方式；压缩资料层级，作品总数取公开目录的 total。
- 概览与作品页默认展示无限作品墙，保留鼠标跟随、拖动、触屏、方向键、Home、Enter、暂停/重置，以及网格视图。
- 分类向完整作者目录查询，默认每页 24 件；明确显示载入数/总数，手动载入更多。当前已载入作品在空间中循环，漫游本身不发目录请求。
- 切换概览/作品/其他标签保留当前筛选、视图与已载入作品；隐藏画廊沿用共享组件的离屏动画停止机制。
- 补齐共享瓦片池的目录覆盖：行数至少容纳全部已载入作品，避免第 2 页以后超出视口池的作品永远不出现。瓦片数只随窗口和明确加载的目录调整，不随漫游距离增长。
- 共享组件提示 ID 使用 useId，避免多个展墙共存时出现重复 ID。
- 总览以紧凑资源/帖子/评论入口替换大面积统计卡片；原公告、介绍、经历与站主联系表单保留。
- 资料与动态分开加载；动态故障不遮住作品，资料/目录/动态提供重试。目录追加失败保留原作品，并重试原页。
- 创作者路由按 handle 隔离实例，拒绝上一作者迟到响应与主题残留；切换语言不重新查询目录或公开资料。
- 私密主页不渲染画廊、不请求作品；仅动态私密时仍展示已发布作品，隐藏动态入口且不请求动态服务。

无限墙展示作品封面与详情链接，实际模型交互继续位于作品详情页。
循环重复不增加真实作品数量；全部数据来自公开目录，不写入作品或演示评分。
