# 原生 0.3.0：网站式视觉与空间交互

## 结果

Windows 客户端以网站 studio.css 的石墨灰 / 淡紫体系为基准重构公开界面：横向导航、编辑式首页标题、精选空间展厅、图片作品卡片、无限作品墙、大幅作品详情以及创作者公开主页。保留后台的分组侧栏。三种主题同步覆盖按钮、输入框、收藏夹选择器、弹窗和预览器。

## 界面与数据

- 首页为默认入口，精选与普通发现使用两个独立公开查询。精选只读 exhibition=true，不把普通作品补进展厅；无入展作品时使用紧凑空状态，让最新作品墙保持可见。
- 空间展厅为原生 OpenGL 子窗口，使用真实图片纹理、透视面板、地台与环线；拖动环绕、Ctrl+滚轮缩放、点击 / 方向键选作品、过渡动画、重置与沉浸模式。滚轮默认继续滚动页面，避免困在画布内。
- 展厅按需绘制，动效关闭时立即定位；弹窗、最小化或隐藏时停止动画。子窗口 region 按滚动位置裁剪到固定导航以下，避免 3D 覆盖按钮或页签。纹理兼容 1.1 路径的二次幂尺寸；正常产品模式不做 GPU 像素读回。
- OpenGL 无法创建时显示真实合格作品图片并说明降级，不伪装 3D，也不改变入展门槛。
- 首页与公开主页可在无限漫游 / 网格之间切换。作品卡片以图片为主体，叠加标题、创作者、价格和悬停反馈；没有恢复已移除的定位十字。
- 作品页使用左侧大幅预览、右侧规格 / 文件 / 社交操作布局；GLB / Draco 可直接嵌入页面，鼠标旋转 / 平移 / 缩放，F 线框 / M 材质 / R 重置；打开后正确取得焦点，方向键留在预览器。Escape 先关闭模型，再返回作品浏览。
- 公开主页读取真实资料、圆形头像、作品数与作品；私密主页不加载作品墙。无简介时显示平台浏览提示，不伪造作者自述。超过一页的作品集保留服务端分页，精选展览同样保留分页入口。
- 收藏夹主界面使用共享按钮样式选择器，旧 ComboBox 隐藏，避免双控件重叠；原生编辑与设置弹窗共享主界面配色。单行输入居中、密码遮罩、原生输入路径与 WS_CLIPCHILDREN 裁剪保持。

## 迁移边界

没有改动网站 / Node / C++ 目录服务或生产记录。公开目录仍为 C++ + PostgreSQL 只读视图；私有工作台继续用现有 API。支付 / 收款确认、管理后台、个人主页深度内容与个性主题编辑、社区编辑和完整账号安全操作尚未原生迁移。模型仍是静态 GLB / Draco / 基础材质范围；没有宣称完整 PBR、骨骼动画或全部格式。

线上只读确认：4 件公开作品，目前 0 件符合精选门槛。没有为视觉验收修改真实推荐分数。空间展厅的正向验收使用独立 PostgreSQL 中的 3 件合格测试作品；分页验收使用超过一页的测试作品集。测试服务器、账号与上传目录独立，结束后清理。
